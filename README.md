# 🐘 PHP Basics — Fundamentos, CRUD e Autenticação

Este repositório reúne um curso prático e progressivo sobre os conceitos fundamentais do **PHP**, cobrindo desde a sintaxe básica, manipulação de formulários, validações, operações de CRUD integradas ao Banco de Dados, até sistemas de autenticação, controle de acesso e upload de arquivos.

---

## 📌 Estrutura do Conteúdo

O repositório está organizado em uma trilha sequencial de aprendizado:

### 1️⃣ Conceitos Básicos e Sintaxe
- `01_helloworld.php`: Primeiro script em PHP.
- `02_opera_variaveis.php` & `02b_opera_variaveis.php`: Declaração de variáveis e operadores.
- `04_condicionais.php`: Estruturas condicionais (`if`, `else`, `elseif`).
- `07_arrays.php`: Trabalhando com arrays numéricos e associativos.

### 2️⃣ Formulários, Validação e Uploads
- `03_formulario.php` & `05_cadastro.php`: Captura de dados de formulários (`POST` e `GET`).
- `08_form_validacao.php`: Validação e higienização de inputs.
- `14_upload.php`: Upload e envio de arquivos para o servidor.

### 3️⃣ Integração com Banco de Dados (CRUD)
- `09_conexao_bd.php`: Conexão do PHP com o banco de dados.
- `10_insercao.php`: Inserindo novos registros (`Create`).
- `11_listar.php`: Consultando e exibindo dados (`Read`).
- `12_atualizar.php`: Alterando registros existentes (`Update`).
- `13_exclusao.php`: Removendo dados do sistema (`Delete`).

### 4️⃣ Autenticação, Sessões e Controle de Acesso
- `06_login.php`: Estrutura simples de login.
- `15a_sistema.php`, `15b_restrita.php` & `15c_logout.php`: Sistema com controle de sessão e páginas protegidas.
- `15d_login.php`, `15d_logout.php` & `15d_perfil.php`: Módulo completo com perfil de usuário.

---

## 📁 Pastas e Materiais de Apoio

- `Aula1/`, `Códigos/`, `Exemplos/Tabelas/`: Diretórios de apoio com materiais práticos das aulas.
- `uploads/`: Diretório de destino dos arquivos enviados via formulário.
- `05a_desafio1.md`, `10a_desafio2.php`, `15d_desafio3.md`: Desafios propostos para fixação do conteúdo.
- `Lição 1 a 9.pdf` & `PHP Introdução.pdf`: Guias e apostilas conceituais em PDF.
- `log_acessos.txt` & `usuarios.txt`: Arquivos texto para testes de leitura/escrita e logs.

---

## 🚀 Tecnologias e Conceitos Utilizados

- **PHP 8+** (Sintaxe moderna, PDO/MySQLi, Manipulação de Sintonias de Sessão)
- **HTML5 & CSS3** (Interface dos formulários)
- **MySQL / MariaDB** (Persistência de Dados)
- **Conceitos:** Sessões (`$_SESSION`), Superglobais (`$_POST`, `$_GET`, `$_FILES`), CRUD e Autenticação.
